# ML-with-pyspark
# PySpark Machine Learning using Ecommerce Customers Dataset

## Project Overview
This project demonstrates how to implement Machine Learning algorithms using PySpark in Google Colab on the Ecommerce Customers dataset.

The project includes:
- Linear Regression
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- K-Means Clustering

The goal is to analyze customer behavior and predict yearly spending using distributed machine learning techniques.

---

# Technologies Used
- Python
- PySpark
- Google Colab
- Machine Learning
- Apache Spark

---

# Dataset
Dataset Used:
- Ecommerce_Customers.csv

Main Features:
- Avg Session Length
- Time on App
- Time on Website
- Length of Membership
- Yearly Amount Spent
